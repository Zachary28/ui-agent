# Midscene UI Agent — Python 使用手册

## 1. 项目概述

**Midscene UI Agent (Python)** 是基于 Midscene 的统一多平台 UI 自动化框架。

核心能力：
- 六大平台统一入口：Browser、Computer、Android、iOS、HarmonyOS、Vitest E2E
- 单次任务执行：连接设备、启动应用、执行操作、截图、断言
- Loop Engineering：可配置的长时间视频播放、弹窗关闭、广告跳过、剧集切换
- 分层配置管理：默认值 → 平台 → 应用 Profile → 任务 → CLI/API 覆盖
- 可恢复执行：指纹验证的 checkpoint，中断后可安全恢复
- 安全机制：高风险操作审批流程，弹窗/广告操作白名单限制

技术栈：Python 3.11+、Pydantic v2、PyYAML、Typer、LangGraph（可选）、Midscene CLI

## 2. 项目目录结构

关键依赖方向：interfaces → application → domain；platforms → infrastructure + domain；infrastructure → domain

## 3. 部署

### 3.1 系统要求
- Python 3.11+、Node.js 18+、npm/npx
- Vitest E2E 额外需要 pnpm
- Android：ADB + 已连接设备
- iOS：WDA + usbmuxd

### 3.2 安装步骤

```powershell
cd ui-agent-python
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

### 3.3 模型配置

编辑 .env 文件配置 MIDSCENE_MODEL_API_KEY、MIDSCENE_MODEL_NAME、MIDSCENE_MODEL_BASE_URL、MIDSCENE_MODEL_FAMILY。
密钥禁止提交到版本控制，不写入日志、checkpoint、事件或报告。

### 3.4 平台前置条件
- Browser：Chrome 已安装
- Android：adb devices 确认设备已连接
- Computer：RDP 端点可达

## 4. CLI 基础用法

```powershell
# Browser
midscene-ui-agent run --platform browser --url https://example.com --goal "验证页面已加载"

# Android
midscene-ui-agent run --platform android --device-id AGYJUT3628001141 --goal "打开设置"

# Computer（需审批）
midscene-ui-agent run --platform computer --goal "截图" --mode live

# iOS / HarmonyOS
midscene-ui-agent run --platform ios --goal "打开设置"
midscene-ui-agent run --platform harmony --device-id xxx --goal "打开设置"

# Vitest E2E
midscene-ui-agent run --platform vitest_e2e --goal "测试登录"

# 检查依赖
midscene-ui-agent run --platform android --device-id xxx --goal "test" --check-dependencies
```

### 常用参数

| 参数 | 说明 |
|---|---|
| --platform | 平台名称（必填） |
| --goal | 操作目标（必填） |
| --url | Browser 目标 URL |
| --device-id | Android/HarmonyOS 设备标识 |
| --mode | plan（仅生成计划）或 live（实际执行） |
| --launch-uri | 要启动的应用包名 |
| --cdp | Chrome DevTools Protocol 端点 |
| --approve | 审批高风险操作 |
| --resume | 恢复指定 run_id |
| --json | JSON 格式输出 |
| --check-dependencies | 检查平台依赖 |

### 输出产物

执行结果写入 artifacts/<run_id>/：
- plan.json — 计划模式下的执行计划
- result.json — 执行状态、步骤、错误
- manifest.json — 产物清单
- events.jsonl — 脱敏后的事件日志
- work/midscene_run/report/*.html — Midscene 原生报告
- work/midscene_run/log/ — 平台日志
- work/midscene_run/report/screenshots/ — 截图

## 5. Python API

```python
from midscene_ui_agent.api import run
from midscene_ui_agent.contracts import AutomationRequest

# 单次任务
request = AutomationRequest.model_validate({
    "platform": "browser",
    "target": {"url": "https://example.com"},
    "goal": "验证页面已加载",
    "mode": "live",
})
result = run(request)
print(f"状态: {result.status}, 运行 ID: {result.run_id}")

# 循环任务
request = AutomationRequest.model_validate({
    "platform": "android",
    "target": {"device_id": "AGYJUT3628001141"},
    "goal": "观看免费电视剧",
    "mode": "live",
    "loop": {
        "operations": {
            "dismiss_popup": {"enabled": True, "interval_seconds": 2},
            "check_playback": {"enabled": True, "interval_seconds": 5},
            "switch_episode": {"enabled": True, "interval_seconds": 300, "strategy": "next_episode"},
        },
        "exit_conditions": {"max_runtime_seconds": 1800},
    },
})
result = run(request)
print(f"退出原因: {result.exit_reason}")
```
